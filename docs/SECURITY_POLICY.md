## 1. 범위
- 수준과 이유: 기본. 로컬 단일 사용자 도구(CLI·GUI)로 계정·서버·네트워크가 없다(PRD §5). 그래서 비밀값·외부 입력·의존성만 다룬다. [U] (D051)
- 서비스 지역·적용 규제: 해당 없음. 개인 데이터를 수집·전송하지 않는다. [U] (D052)
- 이 정책이 다루지 않는 것: 인증·권한·세션·웹 보안(해당 구성요소 없음), ffmpeg 자체의 취약점(사용자가 설치·갱신), 사용자 PC의 다른 계정이 이미 관리자 권한을 가진 경우. [AI]

알려진 위험 (수용): Windows 후보 폴더 `C:\ffmpeg\bin`은 C:\ 상속 ACL(Authenticated Users 수정) 때문에 로컬 사용자 누구나 만들고 바꿀 수 있다. PATH에 ffmpeg가 없을 때만 쓰이고 단일 사용자 PC가 기준이라 그대로 둔다. 여러 사람이 쓰는 PC면 ffmpeg를 PATH에 두도록 안내한다. [U][X] (D053, 2026-10-29 `icacls C:\` 확인)

## 4. 외부 입력 규칙
- MP3 파일은 깨졌거나 악의적일 수 있다고 본다. 파싱 실패는 그 파일만 오류로 끝낸다. [AI]
- 태그 재기록은 임시 파일에 쓴 뒤 `os.replace`로 교체한다 (`gaindb/id3.py`). 게인 적용은 mp3gain처럼 제자리 수정이고, 취소 후 무결성은 수동 회귀로 확인한다 (PRD §6). [X]
- 외부 프로그램은 인자 배열로 실행하고 `shell=True`나 문자열 이어 붙이기를 쓰지 않는다 (`gaindb/decode.py`, `gui/main_window.py`). [X]
- ffmpeg·ffprobe의 실패·빈 출력은 DecodeError로 그 파일만 실패시킨다 (`gaindb/decode.py`). [X] (PRD F6)
