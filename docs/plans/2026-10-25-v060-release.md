# v0.6.0 — 서술 정리 · ffmpeg 찾기 · CI · Release
상태: active | 시작: 2026-10-25 | 근거: PRD §2.1 이번 작업 1~4, F5 마지막 인수 기준, F6 (D028, D031, D033, D038, D039, D044~D046)

목표: 깨진 개발 환경을 복구하고, 파생 사실에 맞게 서술을 고치고, macOS에서도 ffmpeg를 찾게 한 뒤, 3개 OS CI(원본 mp3gain 대조 포함)가 초록인 상태에서 v0.6.0을 GitHub Release로 낸다.
구조:
- `.venv/` — Python 3.15로 재생성 (git 제외)
- `README.md`·`README.ko.md`·`gui/**/*.py` docstring — 서술만 수정
- `gaindb/decode.py` — `find_ffmpeg()` 추가, `_probe_stream_info`·`_spawn_ffmpeg`가 이를 사용
- `gui/main_window.py` — `_on_analyze`·`_on_album_analyze` 시작 전 확인 + 대화상자, `gui/translations/gaindb_ko.ts/.qm` 문자열 추가
- `README.md`·`README.ko.md` — ffmpeg 찾는 위치 설명 갱신
- `tests/test_ffmpeg_locate.py`, `tests/test_mp3gain_parity.py`, `tests/test_gui_album_parity.py` — 새 테스트
- `.github/workflows/ci.yml` — 새 CI
- `build_release.ps1` — onedir zip 생성 추가, `gaindb/__init__.py`·`pyproject.toml` — 0.6.0
전역 제약:
- 공개 함수(`analyze_file`, `decode_pcm`, `decode_pcm_streaming` 등)의 이름·인자·반환 모양 유지
- 테스트는 tempfile 사본에서만, 무손실 판정은 audio_body_sha256 (D019)
- 원본 저작권 헤더 6파일의 고지는 건드리지 않는다 (D027)
- 코어(`gaindb/`) 변경 시 AVD 사본 동기화 대상임을 알린다 (D012)
- git push·git tag·gh release·build_release.ps1 실행 전 사용자 확인 (D041)
- 커밋은 작업마다 1개, Conventional Commits, metapbl / ggoyong2@gmail.com (D030)
