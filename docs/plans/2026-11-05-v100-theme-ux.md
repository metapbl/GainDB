# v1.0.0 — Graphite/Paper 테마 · UX 8개 · macOS 러너 검증 · Release
상태: active | 시작: 2026-11-05 | 근거: PRD §2.1 1.0 작업 1~3, F7 (D057~D063)

목표: GUI가 다크/라이트 테마로 뜨고 UX 결함 8개가 고쳐진 상태에서, 수치·파일 결과는 그대로 유지한 채 v1.0.0을 게시한다.
구조:
- `gui/theme.py`, `gui/assets/icons/` — 스킬이 만드는 생성물 (직접 고치지 않음)
- `gui/__main__.py` — 테마 적용, 앱 이름
- `gui/main_window.py` — 표 QSS, 델리게이트 색, Theme 메뉴, 상태바 문장, 닫기 처리, 삭제 키, 메뉴 활성화, 빈 화면 안내, 퍼센트 라벨, Remove Tags 확인
- `gui/model.py` — clip 색, 실패 행 색
- `gui/translations/gaindb_ko.ts/.qm` — 새 문구
- `GainDB.spec`, `pyproject.toml`, `requirements.txt`, `THIRD_PARTY_LICENSES` — 아이콘, PySide6 ≥6.8, MIT 고지
- `.github/workflows/macos-gui.yml`, `tests/_gui_capture.py` — macOS 러너 검증
- `tests/test_gui_window.py` — 창 동작 테스트
- `gaindb/__init__.py`, `pyproject.toml`, `README*.md`, `docs/release-notes-1.0.0.md` — 버전, 안내, 노트
전역 제약:
- 배치·컬럼(D024), 코어 수치, 태그, CLI 출력은 바꾸지 않는다. 코어 변경은 버전 번호뿐이고 AVD 동기화 대상임을 알린다 (D012)
- 테스트는 tempfile 사본에서만, 사용자 QSettings를 건드리지 않는다. 무손실 판정은 audio_body_sha256 (D019)
- `gui/theme.py`는 직접 고치지 않는다. 앱 고유 규칙은 창 QSS에 둔다
- 로그·오류 원문은 영문 유지 (D011). 새 화면 문구는 tr()과 ko 번역을 같은 작업에서 넣는다
- git push·git tag·gh release·build_release.ps1 실행 전 사용자 확인 (D041)
- 커밋은 작업마다 1개, Conventional Commits, 작업마다 전체 테스트
