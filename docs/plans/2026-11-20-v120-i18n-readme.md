# v1.2.0 — GUI 6개 언어 · README 6개 언어 · Release
Status: active | 시작: 2026-11-20 (계획 시작 커밋 fd91a87) | 근거: PRD §2.1 1.2 작업, F9 (D077~D090)

목표: GUI가 en·ko·zh-CN·ja·es·ru 6개 언어로 즉시 전환되고, 저장값이 없으면 OS 언어(지원 밖이면 en)로 시작한다. README를 6개 언어·표준 구성으로 바꾸고 v1.2.0을 게시한다.

구조:
- `gui/i18n.py` — 지원 언어 표(코드·자기 이름·qm 이름), 로케일 규칙(D083), 저장값 우선(D090)
- `gui/main_window.py` — Language 메뉴 6개 자기 이름(D084), `_FFMPEG_HELP_URL` 6개(D088)
- `gui/translations/gaindb_{ko,zh_CN,ja,es,ru}.ts/.qm` — lupdate → 번역 → lrelease (R§1)
- `GainDB.spec` — .qm 6개(en은 원문이라 5개) 모두 동봉
- `tests/test_gui_window.py`, `tests/test_i18n.py`(새로) — 로케일·메뉴·번역 파일 검사·배치
- `README.md`, `README.{ko,zh-CN,ja,es,ru}.md`
- `gaindb/__init__.py`, `pyproject.toml`, `docs/release-notes-1.2.0.md`

전역 제약:
- 코어(`gaindb/`)는 버전 문자열 말고 바꾸지 않는다. CLI 출력·로그·오류 원문은 영문 (D078)
- dB·ReplayGain·mp3gain·APEv2·ID3v2·ffmpeg와 컬럼 약어는 번역하지 않는다 (D085)
- 새 화면 문구가 생기면 같은 작업에서 5개 .ts 모두에 번역을 넣는다. ko 새 문구는 사용자 검수
- 테스트는 사용자 QSettings를 건드리지 않는다(GaindBTest 이름), 로케일은 mock
- git push·git tag·gh release·build_release.ps1·GitHub About 변경 전 사용자 확인 (D041)
- 커밋은 작업마다 1개, Conventional Commits, 작업마다 전체 테스트

시험 접점: `gui.i18n`의 `resolve_language`·`install_translator`와 offscreen `MainWindow`(메뉴·창 크기·ffmpeg 대화상자), 번역 파일은 .ts XML을 직접 읽는다.
